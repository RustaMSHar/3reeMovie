# 🎬 MovieGeek Hub  

**MovieGeek Hub** is a personal project inspired by the desire to help my mom enjoy watching movies without the hassle of navigating multiple sites. A simple, all-in-one solution for movie lovers.  

> *From one movie geek to another.* 🎥✨  

## 🚀 Features  
✅ Centralized movie streaming  
✅ No more switching between multiple platforms  
✅ Easy-to-use and clean interface  

## 💡 Why This Project?  
Navigating different movie sites can be frustrating. This project aims to simplify the experience by bringing everything together in one place—seamless, intuitive, and enjoyable.

This is just the beginning. More exciting features coming soon! 🚀
